### 1.2 三大断点（为什么流量和 AI 引用还没起来）

**断点 1（P0）：Cloudflare「Block AI bots」把 AI 爬虫全部拒之门外 → GEO 无从谈起**
线上 robots.txt 实测被 Cloudflare 托管规则追加了 20+ 个 `Disallow`，包括：
- **GPTBot、ClaudeBot、CCBot、Google-Extended、anthropic-ai、Claude-Web、Bytespider、meta-externalagent、Google-CloudVertexBot** 等 → ChatGPT / Claude / Gemini(训练侧) 读不到站内内容
- **Baiduspider 也被屏蔽** → 与已部署的百度验证、baidu_push.py、baidu-push-urls.txt（149 条）**直接矛盾**：推送再多，爬虫进来就被 robots 拒了
- 好消息：**PerplexityBot 未在屏蔽名单**，且 `Content-Signal: search=yes, use=reference` 允许检索引用
- **修法**：Cloudflare 后台 → Security/Bots → 关闭或定制「AI Bot 阻止」。GEO 立场建议：放行"检索/引用类"爬虫（GPTBot、OAI-SearchBot、ClaudeBot、PerplexityBot、Perplexity-User、Google-Extended 可选），保留屏蔽纯抓取乱爬的。改完用 `curl https://eternalcnc.com/robots.txt` 复验

**断点 2（P0）：站外存在感 ≈ 0**
Google 检索 "eternalcnc.com" / "Eternal CNC" 几乎无第三方结果——无目录收录、无外链、无社区讨论。欧美采购决策链 = Google 搜索 → 官网 + LinkedIn 复核真实度 → Reddit/论坛搜口碑 → （新增）ChatGPT/Perplexity 要推荐。目前整条链只有官网一环。**这是自然流量起不来的第一原因，比站内任何优化都重要。**

**断点 3（P1）：有内容、缺"可被引用的资产"**
知识库文章多，但缺欧美工程师会收藏/外链/让 AI 引用的**硬资产**：交互式公差对照表、材料对比选择器、表面处理对照表、成本计算器。AI 问答和论坛回帖最爱引用"带数字、带来源的一页纸"。

### 1.3 待修小项（顺手清单）

1. llms.txt 写 `ISO 2768-f`，与铁律拟统一的 `ISO 2768-m` 口径不一致（待确认 m/f 后统一，含中文注释乱码风险复查——用 UTF-8 无 BOM 重存）
2. baidu-push-urls.txt 里 /ru/ 为 0 条，sitemap 里 /ru/ 页面却在——俄语市场要不要做，影响推送优先级
3. GSC 是否已按 2026-09-21 记录切换为 **Domain property**（eternalcnc.com）待确认；未切换则补
4. 风险监控项：某第三方抓取服务的缓存曾返回**色情垃圾标题**（本机直抓正常，网站未被黑），属第三方缓存污染，但建议每周巡检 `site:eternalcnc.com` 是否被污染收录
5. robots.txt 本地文件与线上（Cloudflare 合并后）不一致——修复断点 1 后需重验，避免双重来源混乱

## 二、国外行业偏好（方案依据）

目标画像：欧美的 sourcing engineer、硬件创业团队、R&D 采购。他们的行为规律：

1. **搜什么**：技术长尾词（"7075-T6 vs 6061-T6 machinability"、"anodizing type II vs type III"、"ISO 2768 tolerance chart"、"5-axis vs 3-axis cost"）+ 供应商筛选词（"small batch CNC machining China"、"Xometry alternative"）
2. **信什么**：真实车间照片/视频 >> 库图；具体设备型号+台数；带数字的公差表；带数字的案例；快速报价承诺（你们"2 小时报价 / MOQ 1 件"正是欧美买家最吃的两个点，要在所有渠道反复打）
3. **怎么验证**：LinkedIn 看公司页活跃度 → Reddit/Practical Machinist 搜口碑 → 问 ChatGPT/Perplexity "best small batch CNC machining suppliers"
4. **AI 问答引用谁**：制造商官网（带 FAQ/数据表）、行业目录（Thomasnet/Kompass）、Reddit、YouTube、LinkedIn——**这四类平台必须出现**，AI 才有理由提你
5. **反感什么**：过度承诺（你们的铁律恰好规避了）、模板化中式英语、无实体感的"贸易公司味"

- 所有关键数字带来源（你们周报已经是这个风格，平移到知识库）

**C. 周报照常**（已自动化到 Issue 06，节奏不变）
