客户发来一张图。二十几个尺寸，几乎每一个后面都跟着 ±0.02。

问为什么，答案通常是一句话：要求高。

我们不急着让他放松，也不照单全收。先问一句：**这二十几个尺寸里，对面有东西的，是哪几个？**

## 一、标准本身就在劝你别乱收紧

ISO 2768-1 是“未注公差”的依据，它把一般公差分成四档：f、m、c、v，从精密到很粗。

有意思的是标准自己写的那条建议：**机械加工的金属件，优先用 m 档。**

它还有一句：选档的时候，除了结构上的需要，还要考虑“车间通常能达到的精度”。

这两句话放在一起，说的是同一件事——**公差档位不是越高越好的等级，而是你和一个具体车间之间的一份约定。** 你要的那一档，他得拿手上现有的机床、刀具、量具去守。

所以看到一张图全是 ±0.02，第一件事不是判断“要求高不高”，是判断“这些要求落在哪些尺寸上”。

（m 档在 6 到 30 毫米这一段是 ±0.2 毫米，它和轴承孔 H7 之间差了将近十倍。这笔账我们在[《从想法到能报价的图》](/zh/knowledge/tech-blog/from-idea-to-quotable-drawing/)里算过，这里不重复。）

## 二、紧一档，钱花在哪

“紧了就贵”是一句结论。贵在哪，才是能拿去做判断的东西。至少有五处。

**一是余量。** 公差松的时候，粗加工可以留一大块余量，最后精铣一刀收干净。公差紧到某个程度，余量必须留得很小——留多了最后一刀吃不掉，尺寸就漂出去了。余量小，意味着中间要多加一次半精加工。

**二是参数。** 为了把尺寸守住，进给要压下来，有时候还得换更小、刚性更好的刀。切削时间不是按比例增长的。

**三是测量。** ±0.2 的尺寸，一把卡尺就够了；±0.01 的尺寸，要三坐标、要恒温、可能还要全检。而全检意味着每一件都占一份检测工时。

**四是良率。** 公差带越窄，落在带外的比例越高。带外的件不是“稍微差一点”，是废品或者返工，这份钱要由整批来分摊。

**五是环境与应力。** 紧到一定程度，装夹应力、切削热、材料内应力释放会开始主导尺寸。这个时候要加的不是精度，是工序——去应力、时效、恒温车间。

五条加起来是一句话：**收紧公差买到的不是更好，是更多的工序、更慢的节拍、更多的测量、和更高的报废率。**

## 三、公差紧到毫米的千分之几，是什么概念

前面说的都是在“正常精密”的范围里算账。再往下走一档，规则会变——**不是贵一点，是能做的厂家开始变少。**

我们手上有两个件，图纸上各有一处要求特别高。多处接到这样的图，车间的第一反应都不是算钱，是先掂量自己够不够得着。

先把这个尺度摆出来看。**0.01 毫米是一根头发丝的十分之一。0.005 毫米是这个数的一半，0.002 毫米是它的五分之一。** 到了这个量级，已经不在“加工得好不好”的范畴里，而是进了计量学的门槛。

| 精度要求 | 大致是什么量级 | 通常靠什么守住 |
|---|---|---|
| ±0.05 | 普通精密加工 | 数控机床 + 卡尺、千分尺 |
| ±0.01 | 头发丝的十分之一 | 好机床 + 半精加工 + 千分尺、三坐标 |
| ±0.005 | 一根丝的二十份之一 | 高精度机床 + 恒温，三坐标抽检或全检 |
| ±0.002 | 一根丝的五十份之一 | 高精度机床 + 恒温 + 专门的测量手段 |

（表里的“通常靠什么守住”说的是必要条件，不是充分条件。）

到了 0.002 这个量级，两个条件会同时被卡住。

**第一是机床本身。** 尺寸是机床一个脉冲一个脉冲走出来的，机床的分辨率、丝杠的热伸长、导轨的重复定位，每一项都要比你要守的那个数字小一个量级才谈得上。普通加工中心在这个量级上不是不努力，是它的物理分辨率到不了。所以能做到的，通常是高端的进口高精度机床，或者像北京精雕这一类以精度见长的国产设备。设备这一项，就把绝大多数加工厂筛掉了——这才是“很多厂家不敢接”的真正原因，不是不想赚这个钱，是接了守不住。

**第二是环境。** 要恒温车间。钢材的线膨胀系数大约是每摄氏度百万分之十一到十二——一个一百毫米长的件，温度变化一度，长度就变一变一微米。你要守的量级正好就在这个水平，那么车间的温度波动、机床主轴的温升、甚至测量时手心的温度，都会变成尺寸误差的一部分。

**第三是测量。** 你要知道自己有没有做到，就得有三坐标这类设备，还要在同一个恒温条件下测。量具本身的误差，也必须在你要守的那个数以下。

三条加起来，这个尺寸就不是“一个尺寸”了——它带进来一台设备、一间房、一套测量链，以及为了满足这三样而必须锁死的一整套工艺。

**这解释了一件事：为什么有的图，件看着不难，报价却奇高。** 高的那部分不在批量上，在那一个尺寸上。它把整批件的生产条件都抬了上去，哪怕其余尺寸其实很普通。

也解释了另一件事：**为什么这样的单子，有量也还是不断在换供应商。** 不是钱谈不拢，是守不住——量越大，要保住的件就越多，良率上的一点波动都会放大成整批的报废。做不出来的件，单价再高也是亏的。

（这两个件的具体尺寸落在哪个特征上、当时的报价倍数是多少，我们需要你确认后再写进来。这里先把机理讲清楚。）

## 四、一张图上的尺寸，其实分三类

把那张图上的二十几个尺寸过一遍，它们会自己分成三堆。

| 类型 | 特征 | 该不该紧 |
|---|---|---|
| 配合尺寸 | 对面有东西——要插进去、要贴上去、要转起来 | 值得 |
| 累积尺寸 | 本身无所谓，但它参与尺寸链，几个件装起来靠它 | 值得 |
| 其余尺寸 | 单件自己成立：外形轮廓、避让空间、圆角、外观面 | 紧了是白花钱 |

判断的口诀只有一个问题：**这个尺寸，对面有没有东西？**

有东西，你的紧公差换来的是一句“装得上”；没东西，你的紧公差只换来一张写满合格数字的检验单。

## 五、四个问题，决定这个尺寸值不值钱

第一类和第三类的边界，往往没有表面看起来那么清楚。所以再给四条判据。**四条都答“是”，才值得收紧。**

1. **对面有没有配合件？** 有轴承、有销、有另一个件要贴上来，就是有。
2. **它在尺寸链里吗？** 如果两个件装起来的总间隙，由它和另一个尺寸共同决定，它就在链里。
3. **它是功能面，还是过场面？** 决定定位、密封、旋转、受力的面是功能面；只是为了让刀具通过的面是过场面。
4. **你验得出来吗？** 这一条最容易被跳过。

第 4 条值得单独说。图纸上写 ±0.01，收货只有一把卡尺——那么你、供应商、以及这份图纸，三方都不知道有没有做到。

**公差紧到你验不出来，等于没标。** 它不会让质量变好，只会让价格变高，因为你没法在收货的时候把它退回去。

## 六、能用配合代号写，就别写裸数字

前面回答的是“哪个尺寸值得紧”，这一节回答“紧的那个尺寸该怎么写”。

同样是 Ø30 的孔，你可以写：

```
Ø30 +0.021 / 0
```

也可以写：

```
Ø30 H7
```

这两个是同一个尺寸，但传递出去的信息量不一样。

配合代号描述的是一个孔和一个轴的关系，不是两个孤立的数字。看到 H7，车间立刻知道这是一对配合里那个孔——配套的铰刀、塞规、测量方法都是现成的。看到 +0.021 / 0，他得先换算一下才反应过来这是 H7。

标准里的配合体系只有两种基准：

- 基孔制——孔的偏差固定为 H，下偏差为零，要松要紧靠换轴的代号。H7/g6 是滑配，H7/h6 是紧配，H7/k6 是轻压配。
- 基轴制——轴的偏差固定为 h，上偏差为零，要松要紧靠换孔的代号。

绝大多数情况用基孔制，原因很实际：铰刀、塞规这些量具都是按基孔制配的。写基轴制不是不行，是车间要多备一套东西。

还有一个容易犯的错：把方向写反。孔写 h6、轴写 H7，这张图自己就矛盾了——H 系列是给孔的，h 系列是给轴的。图纸上出现这种组合，供应商只剩一个动作：打电话问你。

所以：**能写配合代号的地方，就别写裸数字。**

## 七、最常见的两种浪费

**第一种，整图收紧。** 把未注公差的 ±0.2 全部改成 ±0.02。价格上去了，而真正决定能不能装的，还是那三五个尺寸。其余那些收紧带来的收益，是零。

**第二种，紧在验不出的地方。** 这种更隐蔽：图纸看起来很专业，但质量和价格两头都没有改善。

不过要反过来提醒一句：**过松也贵。** 配合面留 ±0.2，单件全都合格，装起来就是不行——返工、重做、耽误交期的钱，通常比一开始把那一个尺寸收紧更贵。

所以答案不是“越松越省”。**两头都贵，中间有一个位置是对的**，而找那个位置的办法，就是前面那四个问题。

## 八、同一张法兰，两种写法

**写法 A，看起来严格**

```
未注公差 ±0.05
全部尺寸 ±0.02
```

**写法 B，看起来松**

```
未注公差按 ISO 2768-m
轴承孔 Ø30 H7
止口 Ø50 h6
法兰面相对基准 A 的垂直度 0.02
螺栓孔相对基准 A 的位置度 Ø0.2
其余按未注公差
```

写法 B 的价格更低，装配成功率反而更高。差别不在“紧不紧”，在于**钱花在了有配合关系的那几个特征上**。

而这些特征，恰好就是[《机器人关节与法兰零件》](/zh/knowledge/tech-blog/robot-joint-and-flange-parts/)里说的“形位公差比尺寸公差更要命”的那几个——同轴度、垂直度、位置度，决定关节会不会别劲。

还有一层：这些尺寸最后落到什么状态，还要看要不要做表面处理。一层硬质阳极的膜厚，就能吃掉大半条 H7 公差带，我们在[《处理前还是处理后》](/zh/knowledge/tech-blog/before-or-after-finishing/)里算过这笔账。**图纸上标得再对，处理工序也能把它改掉。**

## 常见问题

**我把公差标紧了，不是更保险吗？**

更保险的是“标对”，不是“标紧”。标紧能保证的事只有一件——价格上去。而价格最后还是要回到你这里。

**那到底多少算紧？**

没有通用答案，但有一条经验分界：一把卡尺能管住的量级，和必须上三坐标才管得住的量级。跨过这条线，成本结构就变了——不是贵一点，是贵在测量和良率上。

**供应商说“能做”，就靠谱吗？**

要接着问一句“用什么保证、怎么验”。能说清楚工艺和量具的，才算答了；只回一句“放心，我们精度没问题”的，通常是没有正面回答。

**我把公差放松了，会不会被做废？**

会。所以关键的那几个尺寸仍然要单独挑出来标——放松的是其余尺寸，不是全部。**未注公差是用来兜底的，不是用来代替标注的。**
